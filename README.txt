DM GULLY CRICKET — Android app starter

This ZIP contains a mobile-first PWA starter with match setup, scoring, batter scorecard, innings switch and match history.

IMPORTANT:
- Current version is a local/demo prototype. Scores do not sync between different phones.
- Public live scoring requires a secure Firebase backend, scorer authentication, database rules and hosting.
- To test: upload the contents of this folder to an HTTPS static host, open the URL in Chrome on Android, then use Chrome menu > Install app / Add to Home screen.
- Play Store publishing requires packaging the hosted app as an Android App Bundle (.aab), signing/testing it, and completing Play Console setup and policy forms. This ZIP is not an APK or AAB.
- A responsible adult may need to handle developer-account registration and publishing requirements.
